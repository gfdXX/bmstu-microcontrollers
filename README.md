## Как собрать

- **STM32 (ДЗ2).** Откройте `homework/hw2-dac7611-usart/stm32-project` в STM32CubeIDE (*File → Import → Existing Projects*). Папка `Drivers` не хранится в репозитории: откройте `HW_2.ioc` и нажмите *Generate Code*, CubeMX восстановит HAL и CMSIS.
- **Лабораторные STM32L476.** В репозитории только пользовательские файлы (`main.c` и т.п.). Создайте в STM32CubeIDE проект под STM32L476 и замените ими сгенерированные.
- **AVR.** Файлы `.asm` собираются в AVR Studio или `avrasm2` с `m16def.inc`.
